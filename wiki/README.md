# Wiki sources

These Markdown files are the source for the project [GitHub Wiki](https://github.com/justcoding121/stream-extended/wiki).

The wiki is a separate Git repository. Changes under this directory are
automatically published by the `Sync GitHub Wiki` workflow after they are
pushed to the `develop` branch. This README contains source-maintenance
instructions and is excluded from the published wiki.

Page naming: a file named `Peeking-TLS-Handshakes.md` is served at `/wiki/Peeking-TLS-Handshakes`. `Home.md` is the wiki landing page.
